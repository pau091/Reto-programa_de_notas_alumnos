# Reto-programa_de_notas_alumnos
#  Gestión de Notas en JavaScript

Este proyecto es una aplicación web interactiva desarrollada con JavaScript que permite gestionar las notas de un curso.

##  Funcionalidades

- Ingreso de nombre y notas de alumnos
- Cálculo de promedio por alumno
- Promedio por certamen
- Promedio general del curso
- Clasificación de alumnos:
  -  Aprobados (≥ 55)
  -  Reprobados (< 55)
- Ordenamiento de alumnos por promedio

## lenguajes usados

- HTML
- CSS
- JavaScript

##  Uso

1. Ingresa el nombre del alumno
2. Ingresa las 3 notas
3. Haz clic en **Agregar Alumno**
4. Luego en **Mostrar Resultados**
